2024 UK Trade Dashboard

Excel dashboard created from UN Comtrade data for goods traded to and from the UK in 2024.

This project demonstrates the use of Excel and its many features (formulas, pivot tables, power query etc.) to create a dashboard from UN Comtrade data. Data was first downloaded from the UN Comtrade website before being imported into Excel where it was cleaned, analysed and transformed into a meaningful dashboard.
